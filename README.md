## 项目简介

**一键工具狗**是面向普通用户的微信小程序工具合集，内置 34 个工具，覆盖计算、生活、图片、文本、学习与办公六类场景。打开即用，没有注册、登录、会员和广告。

它最大的特点是坚持隐私优先的设计理念：所有计算、文本转换与图片处理都在手机本机完成，**没有后端服务、不上传任何输入内容，也不接入统计 SDK**。唯一例外是「汇率计算器」——它会向两个公开汇率接口发起 GET 请求，获取以 USD 为基准的参考汇率并缓存在本机；请求地址固定，不含任何用户输入，金额与换算记录始终留在本机。除该工具外，其余 33 个工具全部离线运行；汇率缓存成功后，断网也能继续换算。

健康、睡眠、工作日等估算类工具同样只在本机按公式计算，图片取色与图片转 Base64 只读取你主动选择的单张图片，Wi-Fi 二维码里的网络名称与密码只写入二维码点阵，均不上传。

除了可以直接使用，它还是一个结构清晰、适合学习和二次开发的 UniApp + Vue 3 + TypeScript 项目示例。

在工程设计上，项目采用业务逻辑与界面分离的方式。每个工具的算法集中在独立的 `logic.ts` 纯函数中（公式、元素等静态数据类工具为 `formulas.ts` / `elements.ts`），配套单元测试。界面层只负责交互与小程序能力调用，便于单独复用或迁移。

## 快速开始

### 环境要求

- Node.js ≥ 18（已在 Node 20 / 22 下验证）
- npm ≥ 9
- 微信开发者工具（稳定版），基础库建议 ≥ 2.15.0

### 获取代码并安装依赖

```bash
git clone https://github.com/201206030/mini-tools.git
cd mini-tools
npm install
```

### 配置 AppID

打开 `src/manifest.json`，把顶层 `appid` 与 `mp-weixin.appid` 两处替换为**你自己的小程序 AppID**；本地调试也可以使用「测试号」。

> 仓库中保留的是原作者的开发用 AppID，仅用于工程可构建，不能用于你自己的预览、上传或提审。本项目不包含任何密钥或凭据。

### 配置 request 合法域名（汇率计算器）

汇率计算器会访问两个公开的参考汇率接口。开发调试时 `src/manifest.json` 的 `mp-weixin.setting.urlCheck` 为 `false`，微信开发者工具可不校验域名直接联调；**真机预览、上传与正式发布必须**在微信公众平台「开发管理 → 开发设置 → 服务器域名」把下面两个地址加入 `request 合法域名`：

- `https://api.frankfurter.dev`
- `https://open.er-api.com`

两个接口都只返回公开汇率数据，无需密钥、无需自建服务，也不会接收任何用户输入。未配置时联网获取会失败，但已保存过汇率缓存的设备仍可离线换算。

### 构建与预览

```bash
npm run dev:mp-weixin      # 开发构建，输出到 dist/dev/mp-weixin
npm run build:mp-weixin    # 生产构建，输出到 dist/build/mp-weixin
```

在微信开发者工具中选择「导入项目」，目录指向 **`dist/build/mp-weixin`**（或开发模式下的 `dist/dev/mp-weixin`），而不是仓库根目录。
`dist/` 已被 `.gitignore` 忽略，首次导入前需要先执行一次构建。

真机验证图片类工具时，请在首次保存图片时允许「添加到相册」权限，被拒绝后界面会提供「去设置」重新授权入口。

## 扩展：新增一个工具

1. 在 `src/tools/<id>/` 下新增 `index.vue`（界面）与 `logic.ts`（纯函数业务逻辑）；公式、元素等静态数据类工具可用 `formulas.ts` / `elements.ts` 命名。
2. 在 `src/data/tools.ts` 的 `TOOLS` 数组追加一条元数据（id、名称、说明、分类、关键词等）。
3. 在 `src/pages/tool/detail.vue` 中静态 `import` 并挂载组件。

完成后，首页展示、分类、搜索、收藏、最近使用会自动生效，无需改动其他页面。

> 小程序不支持 Vue 动态组件，因此详情页采用静态导入 + `v-if / v-else-if` 条件渲染，请沿用这一写法。

## 隐私与安全

- 无后端服务、无云开发、无数据库，不自建服务器，也不需要账号体系。
- 唯一的网络请求集中在 `src/services/exchange-rate.ts`：两个固定的公开汇率接口（Frankfurter 主源 + ExchangeRate-API 开放端点补齐 TWD / RUB），只发起 GET 获取以 USD 为基准的参考汇率；URL 不含任何用户输入，不携带金额、设备标识或个人信息。
- 其余 33 个工具完全离线，业务代码不使用 `uni.request` / `wx.request` / `fetch` / `XMLHttpRequest`（汇率模块除外）。图片取色与图片转 Base64 只通过本机文件系统 / Canvas 2D 读取你主动选择的那一张图片，不扫描相册、不上传。
- 不采集、不上传用户输入的文字、数字、金额、图片、Wi-Fi 名称与密码、健康数据与生成的密码，不保存换算记录，不输出敏感日志。
- 本机仅保存收藏 ID、最近使用 ID + 时间、少量界面偏好，以及一份公开汇率缓存（汇率数值、更新时间、参考日期、来源）；「我的」页可一键清除全部数据。
- 汇率策略：首次联网获取 → 本机持久化 → 24 小时内不重复请求 → 手动刷新或过期才更新；更新失败保留上次有效数据、绝不覆盖；60 秒内重复点击会被节流。
- 相册写入权限仅在实际保存图片时申请，选择图片只允许从相册选取，不调用摄像头。
- 未接入任何第三方插件、UI 框架或统计 SDK，`manifest.json` 已全局关闭 uni 统计。
- 汇率数据为公开参考汇率，仅供参考，不等同于银行实时牌价或实际结汇价。
- 发布前请在微信公众平台配置 `request` 合法域名，见[配置 request 合法域名](#配置-request-合法域名汇率计算器)。

## 贡献指南

完整的贡献流程、提交信息规范与项目约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。以下为要点：

1. Fork 本仓库，基于主分支创建特性分支，例如 `feat/add-xxx-tool`。
2. 保持代码风格一致：中文界面文案、纯函数放在 `logic.ts`、不引入统计 SDK 与新的第三方 UI 框架；除汇率模块外不新增网络请求。新增功能若与现有工具相近，优先作为新模式复用已有工具，而非重复建卡。
3. 提交前确保通过：

   ```bash
   npm run type-check
   npm test
   npm run build:mp-weixin
   ```

4. 提交 PR，说明改动动机、影响范围与验证方式；涉及界面改动建议附截图。
5. Bug 反馈请在 Issue 中提供微信版本、基础库版本、机型与复现步骤。

新增工具只需 3 步（详见[扩展章节](#扩展新增一个工具)）：新增 `logic.ts` + `index.vue`、在 `src/data/tools.ts` 注册、在
`detail.vue` 静态挂载，并同步补充单元测试。
